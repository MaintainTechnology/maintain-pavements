# Glossary

| Term | Meaning (in this context) |
|---|---|
| **SuperBase** | Maintain Pavements' bonding agent (binder), dosed with water *into* an existing unbound yard base and compacted to form a bound hardstand. |
| **Hardstand** | A hard, load-bearing outdoor surface where heavy plant, trucks, trailers or stored materials stand. |
| **Base / roadbase** | The unbound crushed-rock and gravel layer that forms the yard surface. SuperBase treats this in place. |
| **Bound vs unbound** | Unbound gravel relies on interlock and moves under load and water. A *bound* layer is cemented or bonded together and holds its shape. |
| **Scarify** | Rip or loosen the top of the existing base (Jon specifies ~75 mm) so the binder can be mixed through it. |
| **Bull dust** | Very fine, powdery loose dust or silt on a yard surface. It's graded off during preparation. |
| **Ravelling** | Progressive loss of surface stones and particles, the start of potholes. |
| **Rutting** | Wheel-path depressions from repeated loading. |
| **Pumping** | Fines and water being forced up through the surface under repeated loads, which weakens the base. |
| **Corrugating** | Washboard ripples forming across running lanes under turning or braking. |
| **Crossfall / fall** | The slight designed slope across a surface so water runs off instead of ponding. |
| **Design level** | The target finished surface height set by the design. |
| **Dosage design / dosage rate** | The binder-to-water ratio and application rate set for *your* base material and duty. |
| **Moisture processes** | Each watering stage of the lay (mixing, grading, rolling). Jon says the binder is "carried through every moisture process". |
| **Delamination** | A new layer separating from the old layer below. |
| **Wet rolling** | Compacting while the treated base is still moist, using a **smooth drum roller**. |
| **Compaction / density** | How tightly the material is packed. It's measured on site against the density nominated in the dosage design. |
| **CBR (California Bearing Ratio)** | A standard lab test of a base or subgrade's strength (resistance to penetration) relative to a reference crushed rock. Higher is stronger. |
| **Soaked CBR** | CBR measured after the sample is soaked in water (usually 4 days), which represents the worst case. Jon tests soaked "because that is the condition a yard fails in". |
| **Trafficable** | Able to take vehicle traffic. |
| **Organic top coat** | A sprayed dressing over the compacted base on high-wear running lines. |
| **Water cart** | A water truck with spray bars, used here to apply the binder-and-water mix. |
| **Grader** | A motor grader, which trims the base to level and crossfall. |
| **Skid steer / posi-track** | A compact tracked loader. In the PDF it's fitted with a grading or levelling attachment for trimming. |
| **Laydown** | An area for storing product, materials or equipment. |
| **Marshalling** | An area where trailers or trucks queue and are organised for loading. |
| **Eloise Copper Project** | The reference site Jon cites on p.6, where the binder technology was applied across a whole site including truck and forklift hardstand. |
